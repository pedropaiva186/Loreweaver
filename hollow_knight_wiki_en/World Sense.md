# World Sense

thumb|310px|class=darklight-imgVessel. Though bound, you shall know the state of the world.

Hallownest will be whole again.

Function
Displays current Completion percentage in the inventory and on the save file in the main menu. Also shows the number of enemies encountered and required in the Hunter's Journal.

How to Acquire
Found in the Temple of the Black Egg once it has been opened by killing all three Dreamers. The ability itself is granted by inspecting the Lore Tablet beside the Bench.

Trivia
 The World Sense icon appears on the Completion Achievement.
 The name of this ability is not mentioned in the game itself but only in the game files; "world_sense_prompt" is the name of the sprite seen when acquiring the ability.

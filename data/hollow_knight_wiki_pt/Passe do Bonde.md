# Passe do Bonde

center|thumb|122x122pxUm passe vitalício para os túneis de bondes que conectam partes do Hallownest. Estes passes custam uma enorme quantidade de Geo e cada compra requeria autorização do Rei.

 Usos  
Permite que O Cavaleiro use os Bondes da Encruzilhada Esquecida para Terra do Descanso, ou de Ninho Profundo para Bacia Antiga para Borda do Reino. Se o Cavaleiro inspecionar o Bonde antes de adquirir o passe, a descrição será: "Uma porta com um encaixe aberto."
 Como Adquirir 
Encontrado na Linha de Bonde Inacabada no Ninho Profundo nos destroços de um bonde.

 Curiosidades  
 Depois de adquirir o passe, a próxima vez que o Cavaleiro falar com O Último Besouro ele comentará sobre, dizendo: 
"Essa passagem que você segura! Não é para aquela máquina horrível, o bonde? Espero que você não esteja pensando em subir naquela engenhoca grotesca.

Como se uma mera máquina poderia fazer o que os besouros fazem! Tolo... Muito tolo."
